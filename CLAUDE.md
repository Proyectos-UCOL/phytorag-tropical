# PhytoRAG-Tropical Context
Proyecto de Investigación Aplicada y Servicio Social de la Facultad de Telemática (Universidad de Colima).
Director: Dr. Carlos Flores.

## Directrices Principales
- Arquitectura: RAG Híbrido en Python (ChromaDB + BM25 + Gemini API + Pydantic + FastAPI).
- Calidad: Formatear con `ruff format .` y verificar con `ruff check .`.
- Flujo: Ramas `feature/issue-<NUMERO>-<nombre>` con Pull Requests obligatorios a `@cfcortesmx`.
